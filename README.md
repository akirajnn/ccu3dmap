# 天空之城 中正大學

頁首、載入畫面與 favicon 使用中正大學官方校徽：https://www.ccu.edu.tw/var/file/0/1000/img/1331/emblem.png 。來源為官方「關於中正」頁 https://www.ccu.edu.tw/p/404-1000-25575.php 。執行環境無法連線下載，因此目前以官方圖片網址載入，尚未保存為本機資產；圖示顯示需要瀏覽器可連線官方網站。

Vite + Three.js + 原生 JavaScript，無後端或資料庫。使用根目錄原有的 `island+city+3d+model.glb`，不修改原始模型。

## 啟動

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

開啟終端顯示的網址（預設 http://localhost:5173）。正式版本：`npm run build`，以 `npm run preview` 檢視，部署 `dist/` 到靜態伺服器；不能直接雙擊 HTML。

## 導覽與編輯

- 滑鼠左鍵旋轉、滾輪縮放、右鍵平移；手機單指旋轉、雙指縮放及平移。
- 搜尋或點擊標籤可開啟介紹並飛往地標；「全島視角」返回總覽。
- 右上角切換標籤與 FPS；手機以「探索地標」收合側欄。
- 「地標編輯模式」中選擇地標，點模型表面以 Raycaster 取得座標，按「套用座標」。也可以手動輸入 X/Y/Z。
- 「地標編輯模式」按鈕固定顯示於右上方場景控制列下方，桌面與手機都不用展開或捲動側欄；模型載入完成後即可操作。再次點擊「結束編輯模式」關閉。
- 開啟「俯視校正模式」從上方比對建築，可縮放與平移，關閉後恢復原視角。拖曳紅 X／綠 Y／藍 Z 箭頭微調位置；俯視下 Y 軸與視線平行，需切回斜視或手動輸入高度。
- 取點、拖曳及手動輸入會預覽標籤位置，必須按「套用座標」才會保存。「還原未保存調整」恢復目前地標；切換地標或結束編輯也會丟棄未套用調整。匯出只包含已套用資料。
- 「我已人工確認此位置」僅表示編輯者確認，不是程式辨識建築。所有預設位置均為暫定。
- 修改自動儲存於同來源瀏覽器 localStorage；無登入、無管理者權限驗證，不會寫回磁碟。正式修改需「匯出 JSON」並將檔案取代 `src/data/landmarks.json`，再 build。更換專案 JSON 後，先按「重設為專案預設位置」，清除舊瀏覽器資料。
- 一般瀏覽模式點擊模型也會顯示表面座標。編輯期間拖曳不會當成取點。

## 座標與模型

`npm run analyze` 產出 `model-analysis.json`：原始世界範圍、尺寸、節點、材質、貼圖與雜湊。此模型是 Tripo 產出的單一合併 Mesh，只有通用節點名稱，無法由節點確認八個中正校園建築。導覽文字與地標皆為示意，未宣稱模型為校園精準復刻。

原始範圍約 X [-0.489105, 0.489014]、Y [0, 0.223122]、Z [-0.489655, 0.489838]，尺寸約 0.978119 × 0.223122 × 0.979492。執行時保留 Y-up 與原材質貼圖，不額外旋轉，依 Bounding Box 中心置中、等比例縮放最長邊為 100；地標 JSON 使用此**置中且正規化後的場景座標**，不是 GLB 原始座標。原始座標轉換：`場景座標 = (原始世界座標 - 原始中心) × (100 / 最長邊)`。GLB 沒有可確認的實際公尺或北向資訊，因此不推測方位。

相機依球形包圍範圍、垂直與水平 FOV 適配桌面及直式畫面。限制極角、縮放距離、平移目標與最低相機高度，降低穿模風險；不是完整逐三角形相機碰撞系統。

## 替換模型

將新 GLB 放入根目錄，在 `src/main.js` 的 `modelUrl` import 指向新檔，或自行備份後替換同名檔。Vite 會將資產複製並加雜湊到 `dist/assets/`。重新執行 `npm run analyze`（若更名也修改分析腳本路徑）、清除舊地標草稿，重新校正地標並 build。自動置中與等比例縮放不會修改源檔；來源若不是 Y-up，須在 `CampusScene.load()` 計算 Bounding Box 前明確調整模型旋轉。

## 架構與效能

- `src/scene/SkyEnvironment.js`：天空漸層、島嶼周圍雲海與振翅飛鳥；雲朵使用 InstancedMesh，減少 draw calls。減少動態效果偏好啟用時，雲與鳥保持靜止。
- `src/scene/CampusScene.js`：載入、相機、光影、OrbitControls、CSS2DRenderer、GSAP、Raycaster、資源釋放。
- `src/components/interface.js`：導覽及編輯介面。
- `src/main.js`：地標狀態、搜尋、localStorage、JSON 匯出與錯誤處理。
- `src/data/landmarks.json`：八個地標，含 `provisional` 定位狀態。
- 使用 requestAnimationFrame、ResizeObserver、最高 1.75 Pixel Ratio、Frustum Culling、柔和陰影；離頁與 HMR 釋放幾何、材質、貼圖、陰影、Renderer、動畫與控制器。
- 原模型約 39 MB，首次載入需下載與解析，進度達 100% 後仍可能等待貼圖上傳。無法在保持原幾何與外觀的前提下憑空產生 LOD，因此此階段不自動簡化模型。
- 字體使用 Google Fonts，離線會退回系統字體，模型與互動不依賴字體服務。
